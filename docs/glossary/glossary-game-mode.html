GAME MODE

Various game modes limit which ship and upgrade cards are available for squad building.

  • Some game modes have a Ban List and a Restricted List.

  • The two most common game modes are Standard and Extended. The points documents found at www.atomicmassgames.com/xwing-documents detail which ships and upgrades are available during squad buildilng in each of these game modes.
