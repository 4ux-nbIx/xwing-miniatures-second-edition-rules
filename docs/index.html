Introduction

This reference is the definitive source for all Star Wars™: X-Wing™ rules. Unlike the Rulebook, this reference addresses complex and unusual gameplay situations.

The main component of this guide is a glossary of important game terms, organized alphabetically. There are several appendices beginning on page 24.
